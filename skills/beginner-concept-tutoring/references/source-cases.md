# 去身份化教学案例

以下案例保留教学方法及其理由，省略原始记录和身份信息；不是逐字引文。

## C17 从抽象定义到可应用的理解

- **问题：**学习者连续收到概念定义，仍不清楚为什么需要这个机制，也无法把定义用到具体问题中。
- **判断与理由：**补充更多术语没有解决缺口。先呈现不用该机制会遇到的问题，再用生活类比建立直觉，能让原理和用法有落点；类比若混淆邻近概念，反而会形成错误理解。
- **方法：**围绕同一例子依次说明需求、类比、原理和具体用法，再用一两道有变化的题目检查应用。根据回答定位缺口，必要时换例子。术语或技术结论不确定时核实，不把学习者猜测当事实。
- **适用范围：**适合系统学习和纠正抽象讲解，不要求普通短问答变成长课。尚未作答不等于已经掌握；学习者选择继续时可推进并适时回顾，不设置强制答题关卡。

# 去身份化问答案例

以下案例保留表达问题及判断理由，省略原始记录和身份信息；不是逐字引文。

## C18 答案与教学说明各自承担不同任务

- **问题：**一道改善等待体验的题目，最终答案堆满细节，主要措施却散落在解题说明里；缩减机械表达后，又把原本有用的层级删掉了。
- **判断与理由：**答案需要直接回应题目，按少量主要方向给出措施与作用；教学说明解释各方向为何必要。让用户及时看到真实进度可改善等待感受，但不会自动减少处理耗时，因此还要根据实际耗时环节讨论优化。
- **方法：**先明确题目目标，写出总判断和主要方向；再单独从一个合理方案讲起，说明它已解决什么、留下什么真实缺口，由此引出补充方向。核对两部分对应，删去套话而保留必要主句与层级。
- **适用范围：**适合同时需要简洁答案与教学解释的面试题、学习题及方案问答。教学说明呈现概念、假设、取舍和依据，不冒充隐藏推理过程；例题中的时间数字也不成为实际产品保证。
